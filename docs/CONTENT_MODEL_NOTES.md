# Content Model Notes

The foundation must support a multimedia narrative world, not only prose chapters.

Publication collections:

- chronicles
- people
- places
- events
- timeline entries
- artifacts
- media

The future model is:

World → Collections → Entries → Relationships

not:

Series → Volume → Chapter only

The current Phase 2 package populates only `chronicles`. Every other collection
is present and explicitly empty until independently approved source records
exist.
